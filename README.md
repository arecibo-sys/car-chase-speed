# CAR CHASE SPEED VERSION

An ultra-wide, low-profile off-road reconnaissance prototype car chase game, built with three.js.

## 🎮 Play it

https://arecibo-sys.github.io/car-chase-speed/

## 🚗 The vehicle

Per the car design brief, the player car is a compact off-road recon prototype:

- Four enormous exposed mud-terrain wheels with deep block lugs and recessed charcoal rims
- Visible long-travel coilover dampers (bright spring + cylinder) at each corner
- Narrow armored two-seat cockpit, steep raked windshield, roll-cage style frame
- Sealed wedge body in satin graphite (desaturated blue-gray), low-poly disciplined panels
- Two razor-thin white LED signatures at the fascia
- Tall single communications antenna on the rear roof

## 🕹️ Controls

- **Desktop:** Arrow keys / WASD to steer, Shift for nitro
- **Mobile / iPad:** On-screen controls, tilt or touch to steer, nitro button
- Works on smartphones, iPads and desktop from the same single file

## ✨ Features

- Real three.js / WebGL rendering (single self-contained HTML, no external deps)
- Nitro system, live score, near-miss and checkpoint bonuses, best-score persistence
- Traffic, day/night cycle, crash flash, and a chase HUD
- Non-intrusive audio, off by default

## 📄

Single-file `index.html`. No build step, no install — open it in any modern browser.
